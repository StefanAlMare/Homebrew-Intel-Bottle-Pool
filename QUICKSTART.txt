Install / Upgrade
  1. Download standard DMG + SHA256SUMS.txt from v0.3.6.
     Calculate its SHA-256; compare the full digest with its matching line.
     A full -c check needs all listed assets downloaded.
  2. Finish work and Quit before replacement. In v0.3.6 Pause Safely, wait for
     Safely Paused, then Quit. Older apps without this control must finish.
     Stop Now may discard internal compiler progress.
  3. Open DMG. Drag Homebrew Pool.app onto Applications; Replace if intended.
     Keep the previous binary for rollback.
  4. Launch /Applications/Homebrew Pool.app, not the mounted DMG copy.
  5. Existing config/token/custom state_dir/queue/spool are reused.
     Do not delete job.json or reset state. Review, then Resume/Retry.
  6. New users: private HTTPS URL, token/token file, CA only if needed;
     Test Connection, then Save & Finish.

Requirements
  Intel x86_64, macOS 12+ GUI, Homebrew, Python 3.9+; Command Line Tools to build.
  Each formula's own OS/CPU support applies. No silent prerequisite installs.

Data
  Config: ~/.config/intel-bottle-pool/config.json (XDG_CONFIG_HOME respected).
  Existing state_dir retained; default new state ~/Library/Caches/IntelBottlePool.
  UI: ~/Library/Application Support/Homebrew Pool
  Logs: ~/Library/Logs/HomebrewIntelBottlePool
  No user data embedded/reset/migrated by copying app. .test settings separate.
  Do not run standard and .test apps concurrently on one Homebrew.

Pause / Resume
  Pause Safely persists a request and finishes current formula safely.
  Wait during "Pause requested — finishing current formula".
  "Safely Paused" means checkpoint saved; Resume rechecks after restart.
  Stop Now is controlled cancellation, not a snapshot of make.

Uploads / imports
  App Install / Update & Upgrade automatically publish validated output.
  Offline output stays in durable spool for Sync now.
  Scan / Review / Import to Pool handles external existing bottles.
  Auto-import verified bottles: OFF by default; ON adds import only after
  complete error-free Install/Upgrade with no remaining work.
  Capture creates a candidate, not automatic upload.
  A source-installed keg alone is not a confirmed bottle.

Server / compatibility
  Existing schema 1 server needs no reset/redeployment.
  New server: SERVER_SETUP.md; persistent private storage, protected token,
  one service owner, HTTPS/private connectivity. Never expose HTTP + token.
  Q9300 lacks SSE4.2/AVX; incompatible bottles refused.
  Compatibility Options offers reviewed alternatives, not silent downgrades.
  Start at Login starts the agent, not package upgrades.

Status
  Local builds/signing/notarization; no Actions/CI/remote builds.
  Preview: physical HP / MacBook Pro 2012 / Q9300 tests pending.
